## 김정민 · Kim Jeongmin

Java 서버 개발자입니다. 기업용 메신저 솔루션을 개발하고 운영하며, 금융·공공·발전·대기업 37개 고객사의 서버 구축, 서버·DB 이관, 장애 분석, 외부 시스템 연동을 맡았습니다.

### 해 온 일

- **Java 서버**: TCP 소켓 기반 자체 바이너리 패킷을 쓰는 메신저 서버의 로직 수정과 신규 패킷 개발
- **데이터베이스**: Oracle · MS-SQL · MariaDB · Tibero 프로시저와 트리거, 대용량 데이터 정리, 이관과 이중화
- **장애 분석**: 로그와 재현 조건으로 범위를 좁혀 원인을 찾고, 결과를 문서로 남기기
- **연동**: 그룹웨어 SSO, 인사 DB 동기화, ERP 근태, AI 챗봇 API

### 기술

`Java` `Spring Boot` `JPA` `SQL` `Kotlin` `C#` `PostgreSQL` `Oracle` `Linux` `Windows Server` `Git`
