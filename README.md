## 김정민 · Kim Jeongmin

기업용 메신저를 개발·운영하며 금융·공공·발전·대기업 고객사 37곳의 장애 분석과 기술 지원, 서버·DB 이관을 맡아 왔습니다.

### 해 온 일

- **장애 분석**: 로그와 재현 조건으로 범위를 좁혀 원인을 찾고, 수정하고, 장애 보고서로 남기기
- **Java 서버**: 메신저 서버의 로직 수정과 신규 기능 개발
- **데이터베이스**: Oracle, MS-SQL, MariaDB, Tibero 프로시저와 트리거, 대용량 데이터 정리, 이관과 이중화
- **연동**: 그룹웨어 SSO, 인사 DB 동기화, ERP 근태, AI 챗봇 API
